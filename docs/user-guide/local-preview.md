# 操作手冊：在自己電腦上檢視系統畫面

> 給不寫程式的使用者。每一步都寫出「點哪裡、輸入什麼、會看到什麼」。
> 卡住時，把畫面上的錯誤訊息整段複製貼給 Claude Code 就可以。

最後更新：2026-10-20（計畫 2：主檔與案場）

## 一、第一次開啟（或電腦重開機後）

### 步驟 1：開啟 Docker Desktop
1. 按鍵盤左下角的 **Windows 鍵**，輸入 `Docker Desktop`，按 **Enter**。
2. 等視窗左下角出現綠色的 **Engine running**（約 30 秒～1 分鐘）。
3. 視窗可以縮小，**不要關掉**（關掉的話資料庫會停）。

### 步驟 2：在 VS Code 開啟終端機
1. 開啟 VS Code，確認左側檔案總管最上面的資料夾名稱是 **INTERIOR-DESIGN**。
2. 點最上方選單列的 **「終端機」**（英文介面為 **Terminal**）→ **「新增終端」**（**New Terminal**）。
   - 也可以按快捷鍵 **Ctrl + `**（數字 1 左邊那個鍵）。
3. 畫面下方會出現一個黑色（或白色）的輸入區，這就是終端機。

### 步驟 3：啟動資料庫
1. 在終端機輸入下面這行，按 **Enter**：
   ```
   npx supabase start
   ```
2. 等它跑完（第一次可能要幾分鐘；之後約 10～30 秒）。
3. 看到一堆網址（`API URL`、`Studio URL`…）或是 `supabase start is already running`，就代表成功。

### 步驟 4：啟動網站
1. 在**同一個**終端機輸入，按 **Enter**：
   ```
   npm run dev
   ```
2. 看到 `✓ Ready` 和 `Local: http://localhost:3000` 就是啟動好了。
   - ⚠️ 如果 3000 被別的程式占用（例如 WSL 或 Docker），會自動改用 **3001、3002…**，終端機會出現 `Port 3000 is in use … using available port 3002 instead`。**以 `Local:` 那一行顯示的網址為準**，下面所有 `localhost:3000` 都換成那個網址。
3. **這個終端機要一直開著**，關掉網站就會停。要停止時，在終端機按 **Ctrl + C**。

> 也可以直接跟 Claude Code 說「幫我啟動資料庫和網站」，它會幫你執行步驟 3、4。

## 二、登入

1. 開啟 Chrome，在網址列輸入 `localhost:3000`，按 **Enter**。
2. 會自動跳到登入頁。
3. 在 **電子郵件** 欄輸入：`admin@jia.example`
4. 在 **密碼** 欄輸入：`Passw0rd!23`（注意中間是數字 **0**，不是英文 O）
5. 點 **「登入」**。
6. 成功後會進入 **「案場」** 列表頁。

### 可用的測試帳號（全部是虛構資料，密碼都是 `Passw0rd!23`）

| Email | 身分 | 能看到什麼 |
|---|---|---|
| `admin@jia.example` | 甲設計 管理者 | 全部功能（建議先用這個） |
| `designer@jia.example` | 甲設計 設計師 | 主檔、自己被指派的案場 |
| `supervisor@jia.example` | 甲設計 監工 | 只能看被指派的案場，主檔不可編輯 |
| `admin@yi.example` | 乙設計 管理者 | 只看得到乙公司的資料（用來確認兩家公司資料互相看不到） |

### 換帳號
- 桌機：點左側選單最下方的 **「登出」**，再用另一個帳號登入。
- 手機寬度：點右上角的 **「登出」**。

## 三、可以檢視的畫面與操作步驟

### A. 案場列表
1. 點左側選單的 **「案場」**。
2. 上方搜尋框可以輸入案場名稱關鍵字，列表會自動篩選。
3. 搜尋框下面一排圓角按鈕（**全部進行中**、**洽談中**…）可以依狀態篩選。

### B. 新增一個案場（請使用虛構資料）
1. 在案場列表右上角點 **「＋ 新增案場」**（手機寬度則點底部中間的圓形 **＋** 按鈕）。
2. 依序填寫：
   - **案場名稱**：例如 `測試案－信義路三房`
   - **狀態**：點下拉選一個，例如「洽談中」
   - **行政區**：例如 `大安區`
   - **完整地址**：例如 `台北市大安區測試路 1 號 5 樓`（虛構）
   - **坪數**：例如 `32.5`
   - **屋況**：下拉選「中古屋」
   - **樓層**：例如 `5`
   - **電梯**：下拉選「有電梯」
   - **社區規約**：例如 `平日 9:00～17:00 可施工`
   - **業主姓名**：例如 `王小明`（虛構）
   - **電話**：例如 `0900-000-000`（虛構）
   - **Email**：例如 `test@example.com`
   - **身分證字號**：可留空
3. 點最下方 **「儲存」**。
4. 成功後會進入這個案場的詳情頁。

### C. 案場詳情頁
進入方式：在案場列表點案場名稱。

- **編輯案場資料**：點右上角 **「編輯」** → 修改欄位 → 點 **「儲存」**。
- **看業主聯絡資料**：在 **「業主」** 區塊點 **「顯示聯絡資料」**（會留下稽核紀錄）。
  - 身分證字號預設遮住，點旁邊的 **眼睛圖示** 顯示／隱藏。
- **指派成員**：在 **「成員」** 區塊，點下拉 **「選擇要加入的成員」** → 選一個人 → 點 **「加入」**。
- **上傳檔案**：在 **「檔案」** 區塊
  1. 左邊下拉先選檔案類型（例如「平面圖」）。
  2. 點 **「選擇檔案」**，從電腦挑檔案（圖片、PDF、DWG、DXF，單檔 50 MB 以內）。
  3. 手機上可以點 **「拍照上傳」** 直接拍照。
- **刪除檔案**：點檔案旁的垃圾桶圖示 → 跳出確認視窗 → 點 **「確定刪除」**。

### D. 主檔管理（工種、單位、品項、廠商）
1. 點左側選單的 **「主檔」**。
2. 上方有四個頁籤：**工種**、**單位**、**品項**、**廠商**，點一下切換。
3. **新增**：點右上角 **「＋ 新增○○」** → 右側滑出表單（手機從下方滑出）→ 填寫 → 點 **「儲存」**。
   - 例：新增工種，**工種名稱** 輸入 `測試木作`，**排序** 留預設，點 **「儲存」**。
4. **編輯**：點該列右邊的 **鉛筆圖示** → 修改 → **「儲存」**。
5. **調整順序**（工種、單位）：點該列的 **上箭頭／下箭頭**。
6. **刪除**：點 **垃圾桶圖示** → 確認視窗點 **「確定刪除」**。若該資料還被別的地方使用，會顯示無法刪除的原因。

### E. 安全設定（綁定驗證碼 App）
1. 點左側選單的 **「安全設定」**（手機為底部的 **「我的」**）。
2. 依畫面指示用手機上的驗證 App（例如 Google Authenticator）掃描 QR Code，輸入 6 位數驗證碼。
3. ⚠️ 綁定後，**這個帳號之後每次登入都要輸入驗證碼**。只是想看看畫面的話，建議不要綁在常用的測試帳號上。

### F. 直接看資料庫內容（進階，可略過）
1. Chrome 網址列輸入 `localhost:54323`，按 **Enter**。
2. 左側點 **Table Editor**，就能看到每張資料表。
3. 業主電話、地址等欄位是加密過的亂碼，這是正常的。

## 四、常見狀況

| 狀況 | 原因 | 處理方式 |
|---|---|---|
| 網頁顯示「無法連上這個網站」 | 網站沒啟動 | 回到「一、步驟 4」執行 `npm run dev` |
| 登入後出現錯誤、或終端機出現 `connect ECONNREFUSED` | Docker 或資料庫沒啟動 | 確認 Docker Desktop 顯示 Engine running，再執行 `npx supabase start` |
| 種子資料裡的業主姓名顯示異常或讀不到 | 種子資料只放了佔位字串，程式解不開 | 正常現象。自己新增一個虛構案場（「三、B」）就能看到完整效果 |
| 資料變得很亂、想回到最初狀態 | 測試留下的資料 | 跟 Claude Code 說「幫我重建本機資料庫」（會執行 `npx supabase db reset`，**本機所有資料會清空**） |
| 閒置一陣子後被登出 | 閒置 2 小時自動登出（安全設計） | 重新登入即可 |
